# 🚀 How to Use HU Traffic Analyzing System

## Quick Start (3 Easy Steps)

### Step 1: Run the System
Double-click **⚡ QUICK START.bat** (or run `python quick_start.py`)

### Step 2: Select Video Source
In the GUI window:
- Click **"Upload Video"** to select a video file (like the traffic video), OR
- Click **"Use Webcam"** to use your camera

### Step 3: Start Analysis
- Click **"Start"** button
- Watch the live analysis with vehicle tracking and counting!

---

## 📹 Buttons Explained

| Button | What It Does |
|--------|-------------|
| **Start** | Begins video processing and vehicle tracking |
| **Stop** | Stops the analysis |
| **Upload Video** | Choose a video file (.mp4, .avi, .mov, etc.) |
| **Use Webcam** | Switch to your camera (webcam mode) |
| **Export Reports** | Generate 4 types of reports (Traffic, Parking, Rental, Financial) |
| **Reset Counts** | Clear all vehicle counts to start fresh |

---

## 📊 What You'll See

### Left Panel (Video Display)
- Live video feed with:
  - **Colored boxes** around detected vehicles
  - **Track IDs** (unique number for each vehicle)
  - **Yellow line** for counting
  - **Real-time tracking** as vehicles move

### Right Panel (Statistics)
- **Vehicle Counts**: Total, Cars, Motorcycles, Buses, Trucks
- **Parking Status**: Occupied/Available slots
- **Rental Revenue**: Gross, Discount, Net total
- **FPS**: Processing speed
- **Activity Log**: Real-time system messages

## 🐛 Troubleshooting

### "No video source selected" message?
➜ You must click either "Upload Video" or "Use Webcam" **before** clicking Start

### Video not loading?
➜ Make sure the video file format is supported (.mp4, .avi, .mov, .mkv, .wmv)
➜ Check that the file path doesn't have special characters

### Webcam not working?
➜ Close other apps using the camera (Skype, Teams, etc.)
➜ Check your camera privacy settings in Windows

### Slow performance?
➜ Lower resolution videos work better
➜ Close other heavy applications
➜ Check if GPU acceleration is available

### Tracking not accurate?
➜ Use videos with good lighting and clear view
➜ Avoid extreme angles or occlusions
➜ HD videos work best

---

## 💡 Tips for Best Results

1. **Video Quality**: Use clear, well-lit traffic footage
2. **Camera Angle**: Top-down or elevated view works best
3. **Resolution**: 720p or higher recommended
4. **Frame Rate**: 25-30 FPS videos are optimal
5. **Lighting**: Daytime footage gives better detection
